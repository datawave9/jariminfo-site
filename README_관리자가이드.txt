=====================================================================
 자림인포시스템(주) 홈페이지 — 관리자 가이드
=====================================================================

■ 이 사이트는 무엇이 다른가요?
---------------------------------------------------------------------
기존 워드프레스 사이트는 워드프레스 코어, 테마(Elementor), 플러그인을
계속 업데이트해야 하고, 업데이트하다 깨지거나 해킹당하는 문제가
반복적으로 생기는 구조입니다.

이번에 새로 만든 사이트는 워드프레스, 데이터베이스, PHP, 플러그인을
전혀 쓰지 않는 순수 HTML/CSS/자바스크립트 정적(静的) 사이트입니다.
- 업데이트할 "엔진"이 없습니다 → 보안 패치, 플러그인 충돌 걱정이 없습니다.
- 파일을 그대로 호스팅 서버에 올리기만 하면 바로 동작합니다.
- 관리자 로그인 화면, DB 백업 같은 것도 필요 없습니다.

대신 글 내용을 바꾸고 싶을 때는 아래 "내용 수정하는 법"만 알면 됩니다.


■ 폴더 구성
---------------------------------------------------------------------
jariminfo-site/
 ├─ index.html          홈 화면
 ├─ about.html           회사소개
 ├─ products.html         제품소개
 ├─ contact.html          고객지원(문의)
 ├─ css/style.css         디자인 (건드릴 필요 없음)
 ├─ js/site-data.js       ★★★ 실제 문구를 수정하는 파일 (여기만 고치면 됨)
 └─ js/main.js            화면에 뿌려주는 동작 코드 (건드릴 필요 없음)


■ 내용 수정하는 법 (관리자가 직접 가능)
---------------------------------------------------------------------
1) js/site-data.js 파일을 메모장(또는 메모장++, VS Code)으로 엽니다.
2) 회사 전화번호, 주소, 연혁, 실적, 제품 설명 등이 한글 주석과 함께
   정리되어 있습니다. 따옴표(' ') 안의 글자만 바꾸면 됩니다.
   예)
     tel: '062-952-2288',   ← 이 번호만 새 번호로 바꾸면
   전화번호가 홈/제품/고객지원/푸터 등 사이트 전체에 자동으로 반영됩니다.
3) 실적이나 제품을 새로 추가하려면, 바로 위/아래의 비슷한 줄을
   통째로 복사해서 붙여넣고 내용만 바꾸면 됩니다.
4) 저장 후, 이 파일 하나만 다시 서버에 업로드(덮어쓰기)하면 즉시 반영됩니다.
   ※ HTML, CSS 파일은 열어보실 필요가 없습니다.

디자인(색상, 배치)을 바꾸고 싶다면 css/style.css 상단의
":root { --navy: ...; --signal: ...; }" 부분의 색상 코드만 바꿔도
사이트 전체 색이 바뀝니다. (이 부분은 개발자에게 요청하셔도 됩니다.)


■ 오늘 바로 닷홈(dothome) 호스팅에 올리는 법 (FTP 업로드)
---------------------------------------------------------------------
0) ★ 먼저 반드시 확인: 압축파일(zip)을 다운로드하신 뒤,
   반드시 "압축 풀기(압축 해제)"를 하신 폴더 안의 내용을 그대로
   업로드해 주세요. 채팅창에서 파일을 하나씩 개별로 다운로드하면
   css, js 폴더 구조가 깨져서 화면에 디자인이 전혀 적용되지 않고
   글자만 나오는 문제가 생깁니다. 꼭 zip 파일 하나를 통째로 받아서
   압축을 푸신 뒤, 그 안의 index.html / about.html / css / js 폴더
   등을 그대로 사용해 주세요.

1) 닷홈(dothome.co.kr) 로그인 → 상단 [고객센터] 또는 [마이닷홈]
   → 이용 중인 호스팅 상품의 [FTP 정보] 메뉴로 들어갑니다.
   여기서 FTP 서버 주소(보통 회원아이디.dothome.co.kr 형태), FTP 계정
   (보통 가입하신 아이디와 동일), 비밀번호를 확인하세요.
   (가입 시 문자/이메일로 받은 정보에도 있습니다.)

2) 무료 FTP 프로그램인 FileZilla(파일질라)를 설치합니다.
   https://filezilla-project.org (Download FileZilla Client)

3) FileZilla 상단에 호스트(예: 아이디.dothome.co.kr), 사용자명, 비밀번호,
   포트(보통 21)를 입력하고 [빠른 연결]을 클릭해 서버에 접속합니다.

4) 오른쪽(원격 사이트) 화면에서 웹 루트 폴더로 이동합니다.
   닷홈은 보통 접속하면 바로 웹 루트(html 또는 public_html 폴더 하위)
   또는 루트 자체가 웹 루트로 잡혀 있습니다. 폴더 이동 없이 바로
   업로드가 되면 그 위치가 웹 루트입니다. 헷갈리면 닷홈 고객센터
   (홈페이지 내 1:1 문의)에 "웹 루트 폴더 위치가 어디인가요?"라고
   문의하시면 바로 안내받으실 수 있습니다.

5) 왼쪽(내 컴퓨터) 화면에서 압축을 푸신 jarim-info-site 폴더 "안의"
   모든 파일과 폴더(index.html, about.html, css, js, assets 등)를
   선택해서 오른쪽 웹 루트 폴더 안으로 끌어다 놓습니다(업로드).
   ※ jarim-info-site 폴더 자체를 올리는 것이 아니라,
      그 "안에 있는 내용물"을 웹 루트에 바로 올려야 합니다.
   ※ css 폴더, js 폴더, assets 폴더도 반드시 폴더째로 함께
      올라가야 합니다. (파일만 낱개로 올리면 이번에 겪으신 문제가
      똑같이 발생합니다.)

6) 기존에 다른 홈페이지 파일(워드프레스 등)이 이미 올라가 있다면,
   충돌을 막기 위해 새 파일을 올리기 전에 기존 파일을 백업 후
   정리하시는 것을 권장드립니다(원하시면 이 작업도 도와드릴 수
   있습니다).

7) 업로드가 끝나면 브라우저에서 www.jariminfo.co.kr 로 접속해
   정상적으로 보이는지 확인합니다(주소 연결이 아직 안 되어 있다면
   닷홈에서 발급받은 임시 주소로 먼저 확인 가능합니다). 별도의 설치
   과정, DB 설정, 관리자 계정 생성 같은 절차가 전혀 없습니다 —
   파일을 올리는 즉시 끝입니다.


■ 컴퓨터에서 미리보기로 확인할 때 주의사항
---------------------------------------------------------------------
파일을 서버에 올리기 전에 내 컴퓨터에서 먼저 눈으로 확인해보고
싶으시다면, index.html을 더블클릭해서 여는 것 자체는 문제없습니다.
다만 이때도 반드시 압축을 푼 폴더 안의 css, js 폴더가 index.html과
같은 위치에 함께 있어야 디자인과 동작이 정상적으로 보입니다.
(폴더 구조: index.html, about.html, css/, js/ 가 모두 한 폴더 안에
나란히 있어야 합니다.)


■ 브랜드 필름(유튜브 영상) 안내 (갱신)
---------------------------------------------------------------------
홈 화면 "제품" 섹션 아래에 iPECS 공식 유튜브 브랜드 영상이 큰 썸네일
이미지로 표시됩니다. 화면 안에서 바로 재생되는 방식(임베드)이 아니라,
썸네일이나 재생 버튼을 클릭하면 유튜브 새 탭에서 재생되는 방식입니다.

- 처음에는 화면 안에서 바로 재생되는 방식(임베드)으로 만들었는데,
  이 영상은 제조사(iPECS) 측에서 임베드 재생 자체를 막아둔 영상이라
  "오류 153" 이 계속 발생했습니다. 그래서 항상 정상 작동하는
  "클릭 후 유튜브 새 탭 재생" 방식으로 변경했습니다.
- js/site-data.js 안의 video: { ... } 항목에서 관리합니다.
- youtubeId 값만 바꾸면 다른 영상으로 즉시 교체됩니다.
  예) https://www.youtube.com/watch?v=WT20hhceELU 라는 주소라면
      "=" 뒤에 있는 WT20hhceELU 부분만 youtubeId 에 넣으면 됩니다.
- 반드시 iPECS 공식 채널(youtube.com/@ipecssolution) 등 저작권자가
  올린 영상의 ID를 사용해 주세요. 자림인포시스템(주)이 직접 촬영한
  회사/시공 현장 영상이 있다면 유튜브에 비공개 또는 일부공개로 올린 뒤
  그 영상 ID로 교체하는 것도 가능합니다. (자체 촬영 영상은 임베드
  제한이 없는 경우가 많아, 원하신다면 화면 안 재생 방식으로 다시
  바꿔드릴 수 있습니다.)
- title, desc, caption 문구도 함께 원하는 내용으로 수정하실 수 있습니다.


■ 화면 인터랙션 안내 (신규)
---------------------------------------------------------------------
사이트 전반에 다음과 같은 동적 효과가 추가되어 있습니다. 모두 코드에서
자동으로 동작하며 별도 설정 없이 그대로 사용하시면 됩니다.
- 히어로(맨 위) 영역에 은은하게 움직이는 컬러 글로우 배경
- 버튼에 마우스를 올리면 빛이 스치듯 지나가는 효과
- 상단 실적 숫자(2017 / 3 / 12+ / 960,000 등)가 화면에 보이는 순간
  0에서부터 올라가며 카운트되는 효과
- 제품 카드에 마우스를 올리면 입체적으로 살짝 기울어지는 효과
  (모바일/터치 기기에서는 자동으로 비활성화됩니다)
- 제품 이미지 로딩 스켈레톤, 스크롤 등장, 은은한 플로팅 모션
- 브랜드 필름 영상 테두리에 흐르는 듯한 그라데이션 애니메이션
- 사용자가 "동작 줄이기(prefers-reduced-motion)"를 켜둔 경우 모든
  애니메이션이 자동으로 꺼지도록 접근성 처리가 되어 있습니다.


■ 이번 업그레이드 내역 (신규)
---------------------------------------------------------------------
1차 완성본 대비 아래 내용이 추가되었습니다. 전부 js/site-data.js 안의
한글 주석 있는 항목에서 문구 수정이 가능합니다.

- 제품소개 페이지 맨 위 "규모별 비교표" 신설
  (5~50인 → eMG100 / 30~300인 → UCP / 300인 이상 → UCM 처럼
   방문자가 스펙을 몰라도 바로 제품을 고를 수 있게 안내)
- 홈 화면 "도입 프로세스" 5단계(상담→실측→설계→시공→유지보수) 신설
- 홈 화면 "자림인포시스템을 선택하는 이유" 4가지 카드 신설
  (UCM 지정점 인증, 총판 권역 직접 대응, 공공기관 실적, 책임 A/S)
- 파비콘(브라우저 탭 아이콘), 카카오톡·문자로 링크 공유 시 미리보기가
  뜨도록 하는 OG 메타태그 추가
- 검색엔진 노출을 위한 robots.txt, sitemap.xml 추가
- 잘못된 주소로 접속했을 때 뜨는 404 오류 페이지 추가
- 스크롤 시 상단 메뉴에 은은한 그림자가 생기는 효과 추가


■ 참고 사항
---------------------------------------------------------------------
- 이 사이트는 iPECS(舊 에릭슨엘지 엔터프라이즈) 브랜드가 2025년
  "iPECS(아이펙스)"로 사명이 변경된 사실을 반영하여 문구를 구성했습니다.
  회사소개/홈 화면에 사명 변경 안내 섹션이 포함되어 있습니다.
- 문의 폼(이메일 발송)이 필요하시면, 후이즈 호스팅이 PHP를 지원하는지
  확인 후 별도의 mail.php 처리 스크립트를 추가해 드릴 수 있습니다.
  (현재는 전화/이메일 주소를 안내하는 방식으로 구성되어 있습니다.)


■ 제품 이미지 안내 (신규)
---------------------------------------------------------------------
홈 화면 제품 카드, 제품소개 페이지 상세 카드, 상단 헤더의 iPECS 로고에
실제 제품 사진이 표시되도록 업데이트했습니다.

- 이 이미지들은 제조사 iPECS 공식 홈페이지(ipecs.com)에 게재된 정품
  이미지 주소를 그대로 연결(hotlink)한 것입니다. js/site-data.js의
  각 제품 항목에 있는 img: '주소' 값이 그 링크입니다.
- 자림인포시스템(주)은 iPECS 공식 대리점 자격으로 이 이미지를 제품
  홍보 목적에 한해 사용하는 것이므로 별도의 이미지 도용 문제는
  없습니다.
- 다만 제조사 서버 주소이므로 iPECS 측에서 이미지 경로를 바꾸거나
  접속을 제한하면 해당 이미지가 갑자기 안 보일 수 있습니다. (이미지가
  깨지더라도 카드 자체는 정상적으로 보이도록 안전장치를 넣어두었습니다.)
- 더 안정적으로 운영하시려면, 아래 순서로 이미지를 직접 다운로드해서
  자체 호스팅하시는 것을 권장합니다.
  1) js/site-data.js에서 img: '...' 안의 주소를 브라우저 주소창에
     붙여넣어 이미지를 열고, 마우스 오른쪽 클릭 → "다른 이름으로 저장"
  2) 저장한 파일을 assets/img 폴더 안에 넣기 (예: ucm.jpg)
  3) js/site-data.js의 해당 img 값을 'assets/img/ucm.jpg' 로 수정
  4) 저장 후 FTP로 다시 업로드
  이 작업도 요청 주시면 바로 도와드리겠습니다.
- 회사 전경, 매장, 시공 현장 등 자림인포시스템(주)이 보유한 실제 사진은
  여전히 포함되어 있지 않습니다. 파일을 보내주시면 원하는 위치(회사소개
  페이지 등)에 삽입해 드립니다.
